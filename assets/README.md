# Alpirafex brand assets

## Logo horizontal

Los archivos en `logos/` conservan el fondo transparente y la proporción del
logotipo completo:

- `alpirafex-logo-1600.png`: documentación, web y pantallas grandes.
- `alpirafex-logo-1200.png`: cabeceras y materiales de distribución.
- `alpirafex-logo-800.png`: páginas y banners medianos.
- `alpirafex-logo-400.png`: tarjetas y documentación compacta.
- `alpirafex-logo-200.png`: listados y miniaturas.
- `alpirafex-logo-96.png`, `alpirafex-logo-48.png`: interfaces pequeñas.

El archivo original es `../alpirafex-logo.png`.

## Icono

Los archivos en `icons/` contienen únicamente el símbolo ojo/flama, sin texto,
para favicons, menús, instaladores y accesos directos:

- `alpirafex-icon-1024.png`, `-512.png`, `-256.png`, `-128.png`, `-64.png`,
  `-32.png`.

El archivo maestro es `../alpirafex-icon.png`.

## Fondos

Los archivos en `backgrounds/` son fondos panorámicos sin texto para splash,
instalador o escritorio:

- `alpirafex-wallpaper-1920x1080.png`
- `alpirafex-wallpaper-1280x720.png`

El archivo maestro es `../alpirafex-wallpaper.png`.

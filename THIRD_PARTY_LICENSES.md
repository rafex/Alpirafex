# Third-party licensing

Alpirafex is not an official Alpine Linux distribution. It is a separate
meta-distribution that uses Alpine Linux and its packages as a base.

The MIT license in [`LICENSE`](LICENSE) applies only to Alpirafex-owned
scripts, configuration, meta-packages and branding in this repository.

The Alpine kernel, BusyBox, APK tools, Xorg, i3, picom, rofi, OpenSSH and all
other third-party packages retain their original licenses and copyright
notices. Package metadata and upstream source notices must be preserved when
packages are redistributed.
